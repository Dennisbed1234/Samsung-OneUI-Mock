# Samsung One UI Mock

Web-based **Galaxy · One UI** simulator (Android-style shell).

## Features

- Samsung-style frame, punch-hole camera, side buttons
- Boot → lock screen → home
- Home pages, dock, app drawer (swipe up)
- Quick Settings (pull status bar / tap clock area)
- Working apps: Phone, Messages, Chrome, Camera, Gallery, Settings, Calculator, Clock, Contacts, Calendar, Weather, Galaxy Store, WhatsApp Web launch
- 3-button navigation

## Local

```bash
npx serve .
```

## Vercel

Import repo → Framework: Other → Output: `.` → Deploy
